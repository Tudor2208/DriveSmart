This is my diploma project which involved developing a traffic assistance Android application aimed at increasing road safety. The application captures images using the phone's camera and uses convolutional neural networks for the detection and recognition of traffic signs, as well as for predicting necessary turns on the road so that the driver can adjust his speed accordingly. Based on the analyzed environment, both visual and auditory warnings will be provided.
# Key Features
The main features include:

- An advanced traffic alert system that allows users to receive audible warnings about detected traffic signs and predictions for necessary turns along the route.
- The ability to view detailed summaries of completed trips.
- Extensive profile customization options to enhance the user experience.
For implementing the traffic alert system, I used two types of deep learning models: one for object detection, designed to identify traffic signs, and another for image classification, which categorizes images into three possible classes: left turn, right turn, or straight road. These models predict the necessary turns users should make along their journey.
